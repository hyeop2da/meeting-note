시작하는 방법
  1. 위의 ‘● 녹음 시작’을 누르고, 마이크 사용을 허용하세요.
  2. 말하는 내용이 이 창에 글자로 나타납니다. (제미나이 전사: 약 30초 간격으로 한꺼번에 / 기기 음성인식: 즉시)
  3. 발언자가 바뀌면 위의 이름 버튼을 눌러 주세요. 이후 발언에 이름이 붙습니다. (회의 정보에 참석자를 적어 두면 ‘📋 참석자 명단 불러오기’로 버튼이 한 번에 만들어집니다)
  4. 오른쪽 메모장에 자유롭게 메모하세요. 🕐 시각 버튼은 현재 시각을, ⭐ 방금 발언 버튼은 방금 나온 말을 메모로 가져옵니다.
  5. 휴식 시간에는 일시정지, 간담회가 끝나면 ‘■ 종료’를 누르세요.
  6. 오른쪽 ‘✨ AI 회의록’ 탭에서 화자 구분 전사와 결과보고 초안을 만들 수 있습니다.
※ 모든 기록은 이 기기 브라우저에 자동 저장됩니다. 창을 실수로 닫아도 다시 열면 이어집니다.
※ iPad: 녹음 중에는 다른 앱으로 전환하거나 화면을 잠그지 마세요(녹음이 멈춥니다).

    ⚙ AI(제미나이) 설정

    API 키 발급 방법 (무료, 1분)
    1. 브라우저(사파리·크롬)에서 aistudio.google.com 에 접속해 구글 계정으로 로그인합니다.
    2. 화면의 ‘Get API key’(API 키 가져오기)를 누릅니다.
    3. ‘Create API key’(API 키 만들기)를 누르고, 만들어진 키 옆의 복사 버튼을 누릅니다.
    4. 아래 칸에 붙여넣고 ‘연결 확인’을 누르면 끝입니다.
    ※ 제미나이 앱 구독(학생 플러스)과 API는 별개이며, API는 무료 등급으로 사용할 수 있습니다.
    제미나이 전사 간격
    기본은 ‘Flash’ 계열(빠르고 무료 한도가 넉넉함)을 권장합니다. ‘연결 확인’을 누르면 사용 가능한 모델 목록이 갱신됩니다.
    🔒 보안 안내
    · ‘제미나이 준실시간 전사’를 쓰면 녹음 음성이 약 30초마다 구글 서버로 전송됩니다. 민감한 간담회는 ‘기기 음성인식’ 또는 ‘전사 끄기’를 선택하세요.
    · API 키는 이 기기의 브라우저에만 저장되며 다른 곳으로 전송되지 않습니다(구글 호출 시에만 사용).
    · 무료 등급으로 보낸 내용은 구글의 서비스 개선에 활용될 수 있습니다. 개인정보·민감 사안이 포함된 간담회는 ‘빠른 정리’(텍스트만 전송) 또는 AI 정리를 생략하세요.

    ❓ 사용법

    간담회 당일
    1. 상단에 제목과 📋 회의 정보(일시·장소·참석자)를 입력합니다.
    2. ● 녹음 시작 → 마이크 허용. 왼쪽에 발언이 실시간으로 적힙니다.
    3. 오른쪽 메모장에 메모합니다. 🕐 시각은 시각 찍기, ⭐ 방금 발언은 방금 나온 말을 메모로 가져오기.
    4. 발언자: 전사 창 위의 이름 버튼을 누르면 그 뒤 발언에 이름이 붙습니다. 잘못 붙은 이름은 발언 앞 이름표를 눌러 고칩니다(이어지는 같은 발언자 발언도 함께 변경).
    5. 휴식 땐 일시정지, 끝나면 ■ 종료. 종료 후에도 이어서 녹음할 수 있습니다.
    간담회 후
    1. 왼쪽 발언의 시각 버튼을 누르면 그 부분 녹음을 다시 들을 수 있습니다.
    2. ✨ AI 회의록 탭 → ‘AI 회의록 만들기’ → 결과보고 초안을 복사해 한글(HWP)에 붙여넣습니다.
    3. 💾 저장 → 📤 공유로 기록·녹음 파일을 ‘파일’ 앱, 카카오톡, 메일 등으로 보내 보관하세요.
    iPad에서 쓰실 때 꼭 확인
    1. 사파리로 여세요. 처음 한 번 설정 → 일반 → 키보드 → ‘받아쓰기 활성화’를 켜 두어야 실시간 전사가 됩니다.
    2. 녹음 중에는 다른 앱 전환, 화면 잠금, 사파리 탭 이동을 하지 마세요. 녹음과 전사가 멈춥니다. 멈추면 안내가 나오며 ‘이어서 녹음’으로 계속할 수 있습니다.
    3. 충전기 연결을 권장합니다. 1~2시간 녹음 시 배터리 소모가 큽니다.
    4. 사파리는 7일 이상 열지 않은 사이트의 저장 기록을 지울 수 있습니다. 간담회가 끝나면 꼭 ‘📤 공유’로 파일을 보관하세요.
    5. 외장 마이크(USB-C 핀마이크, 무선 마이크 수신기)를 연결하면 인식률이 크게 오릅니다.
    잘 쓰는 요령
    1. PC는 크롬·엣지, iPad는 사파리에서 사용하세요. 인터넷 연결이 필요합니다.
    2. 기기 내장 마이크보다 회의용 스피커폰·외장 마이크를 테이블 가운데 두면 인식률이 크게 오릅니다.
    3. 녹음 중에는 화면이 자동으로 꺼지지 않도록 설정됩니다.
    4. 간담회 시작 시 “기록을 위해 녹음합니다”라고 사전 고지해 주세요.
