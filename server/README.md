# 간담회 기록 도우미 · 맥미니 전사 서버

맥미니에서 위스퍼(whisper.cpp, 애플 칩 가속)로 한국어를 받아 적는 개인 서버입니다.
음성이 구글 등 외부로 나가지 않고, 사용량 한도가 없습니다.

## 설치 (맥미니 터미널에 한 줄)

```bash
curl -fsSL https://hyeop2da.github.io/meeting-note/server/setup.sh | bash
```

- 관리자 암호가 필요 없습니다. 처음에는 엔진 빌드와 모델(약 550MB) 다운로드로 수 분이 걸립니다.
- '개발 도구 설치' 창이 뜨면 설치를 누른 뒤 같은 명령을 다시 실행하세요.
- 끝나면 **서버 주소**와 **접속 키**가 화면에 표시됩니다.

## iPad에서 쓰려면 (Tailscale)

1. 맥미니와 iPad에 App Store에서 **Tailscale**을 설치하고 같은 계정으로 로그인합니다.
2. login.tailscale.com/admin/dns 에서 **MagicDNS**와 **HTTPS Certificates**를 켭니다.
3. 맥미니에서 설치 명령을 한 번 더 실행하면 `https://…ts.net` 서버 주소가 표시됩니다.
4. 앱 ⚙ 설정 → **🖥 맥미니 서버** → 주소·접속 키 입력 → **연결·속도 시험**.

## 구성

| 파일 | 역할 |
|---|---|
| `install.sh` | 엔진 빌드, 모델 받기, 접속 키 생성, 맥이 켜지면 자동 실행(launchd) 등록, Tailscale 연결 |
| `meetnote_server.py` | 접속 키 확인, 웹앱 주소만 허용, 무음·흔한 엉뚱한 문장 거르기, 기록 백업 (파이썬 표준 라이브러리만) |
| `uninstall.sh` | 서버 끄기·자동 실행 해제 (기록 백업은 남김) |

설치 위치: `~/MeetNoteServer` (엔진·모델·로그, 기록 백업은 `data/`)

## 24시간 운영 권장
시스템 설정 → 에너지: '자동으로 잠자기 방지' 켜기, '정전 후 자동으로 시동' 켜기.
